## いま（v0.4 開発中 / v0.3.0 ベース）

| 領域 | 内容 |
|------|------|
| 認証 | Google ログイン・新規登録（1 アカウント = 1 プレイヤー） |
| プロフィール | 名前・アイコン・メモ、**退会** |
| 試合 | 追加・編集・削除（管理者）、第〇戦番号、開催日時 |
| ランキング | **通算 / シーズン別** 切替、シーズン別ポイントルール表示 |
| シーズン管理 | `/admin/seasons`（期間・表示名・ランキング表示・ポイントルール） |
| 個人成績 | 詳細画面、シーズン切替、直近5試合、各種率、連続入賞 |
| ホーム | お知らせ（ヘッダー・未読バッジ・種別）— [`design-announcements.md`](./design-announcements.md)、アクティビティ、ランキング TOP3、直近試合 |
| 共有 | Discord 共有文 |
| 運用 | BAN、追加管理者、メンテ画面切替、`VITE_LEAGUE_ID`、開発環境バナー |

**v0.4 リリース前:** Firestore Rules デプロイ、[`test-cases-v0.4.md`](./test-cases-v0.4.md) 手動確認、[`release-v0.4.md`](./release-v0.4.md) のお知らせ投稿。

**任意（v0.4 外）:** 終了シーズン最終成績専用画面、試合一覧のシーズンフィルタ。
