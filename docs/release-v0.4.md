# Rivalt v0.4 リリースノート

PR 本文・デプロイ前確認用のまとめ。詳細設計は [`design-v0.4.md`](./design-v0.4.md)。

---

## アプリ内お知らせ（掲載用文案）

管理者は `/admin/announcements` から以下を投稿してください。  
画面フッターには `package.json` の semver（**v0.4.0**）が自動表示されます。

| 項目 | 内容 |
|------|------|
| タイトル | `v0.4.0 アップデートのお知らせ` |
| 種別 | アップデート（`update`） |
| ピン留め | 任意（おすすめ: ON） |

**本文（コピペ用）:**

```
皆さん、こんにちは。

Rivalt を v0.4.0 にアップデートしました。主な変更点は次のとおりです。

■ シーズン（イベント期間）
・試合・ランキング・個人成績を「シーズン」単位で見られるようになりました
・通算ランキングはこれまでどおり全試合の合計です
・ホームに現在のシーズン名と日程を表示します

■ お知らせ
・ヘッダのメガホンから一覧・詳細を開けます（ホームの長い告知欄は廃止）
・種別（重要・アップデート・不具合修正）と未読バッジに対応しました

■ 管理者向け
・シーズンの期間・表示名・ランキングへの表示／非表示を設定できます
・シーズンごとにポイントルール（1位の加点など）を変えられます（既存試合の pt は変わりません）

ご不明点は運営までどうぞ。これからもよろしくお願いします。
```

---

## Summary

v0.4 は **シーズン管理**（試合の紐づけ・通算/シーズン別ランキング・個人成績切替）、**ホームお知らせ UI**（モーダル・種別・未読）、**管理者のシーズン運用**（期間・表示名・重複チェック・ランキング表示・ポイントルール）を含む。

---

## 新機能

### シーズン

- `games.seasonId`、通算 / シーズン別ランキング・プレイヤー詳細
- `/admin/seasons`: 期間、表示名（24文字）、`showInRanking`、**シーズン別ポイントルール**
- 新規試合の `seasonId`: **期間内シーズン優先**（`resolveActiveSeasonId`）、該当なしは `config/league.activeSeasonId`
- 期間重複は保存拒否。状態は期間から自動（開催中 / 開始前 / 終了 / 未設定）
- `SeasonUserDisplay`（ホーム・ランキング）

### お知らせ

- ヘッダメガホン → 一覧 / 詳細モーダル（`createPortal`）
- 種別 `important` / `update` / `bugfix`、管理者テンプレート
- 未読: `players/{uid}/announcementReads/{announcementId}`

### ポイントルール（シーズン単位）

- `seasons/{id}.pointRules`（未設定は標準 +7/+5/+3/+1/0/-2）
- 試合登録・編集時にその試合のシーズンルールで pt 計算（保存済み pt は不変）

## デプロイ時の注意

1. **Firestore Rules** を必ずデプロイ  
   `npx firebase deploy --only firestore:rules`  
   （`announcements.category`、`announcementReads`、シーズン系）
2. 本番ビルド **`VITE_LEAGUE_ID=main`**
3. 本番 `main` で Season 1 登録・期間・お知らせ投稿のスモークテスト
4. [`test-cases-v0.4.md`](./test-cases-v0.4.md) の TC-SN4〜6・HM・AN・未読を手動確認
