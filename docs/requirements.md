# 要件定義

## アプリ概要

Rivalt は、Discord の友達内で行うポーカーの試合結果を記録し、ランキング・個人成績・過去試合を管理する Web アプリです。

## 目的

- 試合結果を簡単に記録する
- 友達内ランキングを自動集計する
- Discord に共有しやすい結果文を生成する
- Excel やスプレッドシートより見やすく管理する

## v1.0.0（製品版）で目指す機能

段階的に v0.4〜v0.7 で実装し、v1.0.0 で整理・安定化する。

| 領域 | 内容 |
|------|------|
| コア | プレイヤー登録、試合結果入力、ポイント自動計算、ランキング、個人成績、過去試合一覧、Discord 共有文 |
| シーズン | シーズン別成績・ランキング、通算との切替、シーズン終了時の最終成績（v0.4） |
| グループ | フレンド・グループ作成、招待、グループ内ランキング・シーズン・試合管理（v0.5） |
| 運用 | リザルト申請・承認、権限整理、Rules 強化、バックアップ、操作ログ（v0.6） |
| 製品化 | スマホ UI、利用規約・プライバシーポリシー、安定運用（v1.0.0） |

詳細な版ごとの内訳は [`docs/roadmap.md`](./roadmap.md) を参照。

## v1.0.0 まで作らない機能

- ポーカーゲーム本体
- チップ推移管理
- **大会・イベント機能**（v1.0.0 **以降** の Coming Soon として検討）
- Discord Bot 連携（将来検討）

## 今後も実装しない機能

- リアルマネー・賭け金・精算・賞金・換金可能ポイントなど、金銭の授受を前提とした機能

アプリ内ポイントはランキング用スコアであり、金銭的価値を持たない。
